# Raylib 2D ASCII Match3

This project is a modified version of [erikyuzwa/raylib-2d-ascii-match-3](https://github.com/erikyuzwa/raylib-2d-ascii-match-3), a Match-3 game built using C and Raylib.

Changes & Setup:

- Made minor code adjustments and optimizations.

- Added a Makefile for streamlined building.

- Developed and tested on Windows 11.

Special thanks to @erikyuzwa for the great tutorials!
